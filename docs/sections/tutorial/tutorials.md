# **Tutorials**

The following tutorials will outline key examples of how to interact with this repository.

## 1. [SiPyCo RPC Control 🔗](examples/sipyco.md)

This tutorial demonstrates how to start your Thorlabs application in a local server or Docker container, and interact with it using [SiPyCo's](https://github.com/m-labs/sipyco) Remote Procedure Call (RPC) tool.

## 2. [ARTIQ Control 🔗](examples/artiq.md)

This tutorial demonstrates how to configure Thorlabs devices in the [ARTIQ device database](https://m-labs.hk/artiq/manual/developing_a_ndsp.html#integration-with-artiq-experiments) and interact with them using ARTIQ's control system.

## 3. [Docker Container 🔗](examples/docker.md)

This tutorial explains how to build and run the Thorlabs application in Docker containers for isolated deployment.

## 4. [Local Server 🔗](examples/local.md)

This tutorial demonstrates how to start a local server for the Thorlabs application without Docker.
